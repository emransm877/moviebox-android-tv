# Security policy

Do not post credentials, session tokens, private logs, signed stream URLs,
keystores, certificate passwords or device identifiers in public issues. Use
GitHub's private vulnerability-reporting channel when available.

The maintained series is 0.1.x. The app uses local frontend assets, bounded native
HTTPS requests, Media3 and private storage. Release WebView debugging is disabled.
New dependencies and upstream endpoints require review.

Optional updates point to this project and require user action. No root,
automatic code installation or disabling of security tools is required. Reports
should include the version and minimal reproduction with private data removed.
